## 🛠️ Технический стек

### Языки программирования
- **Python** (продвинутый уровень)
  - NumPy, Pandas для обработки данных
  - Scikit-learn для ML
  - Matplotlib, Seaborn для визуализации
  - Joblib для сериализации

### Machine Learning
- **Supervised Learning:** Classification, Regression
- **Ensemble Methods:** Random Forest, Gradient Boosting
- **Model Evaluation:** Cross-validation, Confusion Matrix, ROC-AUC
- **Hyperparameter Tuning:** GridSearchCV, RandomSearchCV
- **Feature Engineering:** Selection, Transformation, Creation

### Data Engineering
- **Data Cleaning:** Missing values, Outliers, Duplicates
- **Feature Encoding:** Label, One-Hot, Target Encoding
- **Scaling:** StandardScaler, RobustScaler, MinMaxScaler
- **Pipeline:** Preprocessing → Training → Validation → Deployment

### ML Ops
- **Model Persistence:** Joblib, Pickle
- **Production Code:** Error handling, Logging, Monitoring
- **Model Deployment:** REST APIs, Batch predictions
- **Version Control:** Git, GitHub

### Tools & Libraries
- **Jupyter Notebooks** для EDA и prototyping
- **VS Code / PyCharm** для разработки
- **Git** для version control
- **Docker** (базовый) для containerization
- **SQL** для работы с базами данных
