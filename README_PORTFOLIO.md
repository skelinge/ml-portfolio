## 🚀 КУДА ЗАГРУЗИТЬ - ТОП-3 ВАРИАНТА

### 1️⃣ GitHub (РЕКОМЕНДУЕТСЯ) ⭐

**Почему:** Бесплатно, профессионально, работодатели проверяют

**Как:**
1. Создайте аккаунт на github.com
2. Создайте репозиторий `ml-portfolio`
3. Следуйте инструкции из `ML_Portfolio/QUICK_START_GITHUB.txt`

**URL вашего портфолио:**
```
https://skelinge.github.io/ml-portfolio
```

**Детали:** Смотрите файл `ML_Portfolio/GITHUB_SETUP_GUIDE.md`

---

### 2️⃣ Kaggle Notebooks

**Почему:** Сообщество DS, легко делиться ноутбуками

**Как:**
1. Зарегистрируйтесь на kaggle.com
2. Create → New Notebook
3. Загрузите ваш Python код
4. Сделайте Public

**Детали:** Лучше для отдельных проектов, а не всего портфолио

---

### 3️⃣ Google Colab

**Почему:** Интерактивные примеры, бесплатный GPU

**Как:**
1. Зайдите на colab.research.google.com
2. Создайте новый ноутбук
3. Загрузите код
4. Share → Public link

**Детали:** Для демонстрации кода, не для резюме
